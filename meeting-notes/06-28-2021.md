### Notes

This was a short meeting because I encountered implementation issues with the UDF branch that I did not foresee. Merging this pull request needs to take precedence over the remainder of our work, so everything else is on hold until I can resolve these issues (see below).

### Progress from Last Week

Primary goal for last week was to merge the UDFs PR. This did not happen because I started writing additional tests for the implementation and encountered a number of troubling bugs. The two I am currently focusing on are (briefly):

- An issue with the lifetime management for execution context (`ExecutionContext`) query parameters. The implementation of UDFs changes the way that query parameters are managed, and somehow we messed up the lifetime management for these values such that we encounter a use-after-free that results in a segmentation fault. I believe I know how I will address this issue.
- An issue with the implementation of code generation of TPL lambdas. This issue manifests in simple TPL tests for lambda expressions (the simplest possible use of a lambda triggers the bug) as a segmentation fault during code generation. The issue stems from the C++ lambda that is used to defer processing of the lambda expression itself until the entirety of the function body in which it appears has been resolved. I have not yet been able to determine precisely what it is in the body of the C++ lambda that is triggering the fault.

### Goals for This Week

- Fix the lifetime issue with execution context query parameters.
- Determine the root cause of the issue with the implementation of code generation for TPL lambdas.
