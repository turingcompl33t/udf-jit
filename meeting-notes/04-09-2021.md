### JIT Compilation for User-Defined Functions

Meeting Notes

_April 9th, 2021_

### Notes

I reached my "sprint" goal of bringing in all of the existing code for UDF JIT from Tanuj's branch this week. This is a big step forward, but plenty of work remains to be done. Remaining tasks for UDF JIT support include the following:

- Review design decisions in implementation. The blast radius of UDF JIT is pretty massive (around 100 files). Many of these changes are a result of API updates to components that play a critical role in the system e.g. the API for the `Pipeline` class was updated slightly, necessitating changes in various places to account for the new API. I'd like to review these updates to ensure they are indeed necessary, and to make sure that I understand _why_ they were made in the first place.
- I am currently experiencing a linker error that did not manifest until the final stages of the integration. The first step in addressing this is top attempt a build on one of the development machines instead of my local machine and see if the issue persists.
- There are a number of places where the implementation is currently "commented out" to simplify the integration process (e.g. this type did not exist when I wanted to compile and merge this particular file). I need to go in and include this implementation.
- There are a huge number of places in which I identified `TODO`s for myself while performing the integration. These range from questionable naming decisions, to lack of documentation, to questionable implementation. Naturally, I need to revisit all of these.
- Testing. Currently, there are almost no tests that actually verify the new functionality. I will need to write a substantial number of tests to convince myself and the rest of the team that the new features behave as intended.

The takeaway is, this was a productive week, but a number of important tasks remain to be completed before finalizing this first phase of the project.
