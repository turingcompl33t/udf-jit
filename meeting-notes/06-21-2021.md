### Progress from Last Week

I spent the majority of last week working on the UDF PR. We had a non-trivial number of regressions - existing tests that started failing with the introduction of the UDF PR - that I had to spend time debugging and subsequently fixing. It also seems that the implementation itself is incomplete... for instance, there were a number of TPL constructs that simply did not have the appropriate code generation mechanisms in place (e.g. no visitor implementation for TPL `break` statements). This is a bit disconcerting because it makes me think that we don't have tests that exercise much of the implementation. This will be something that I need to take a closer look at.

Another thing I spent some time on last week was reviewing existing research on database code generation engines. As we discussed last week, there are actually relatively few systems / groups that work on this particular problem. I spent quite a bit of time reading and understanding the work in _Architecting a Query Compiler_ and _Architecting a Query Compiler, Revisited_. These are both interesting papers, and they are even more interesting when taken together because they advocate very different approaches to the architecture of a DBMS query compiler. This is a broader discussion, but I seriously think there is tons of interesting work to be done in this space that is currently receiving very little attention. I think I am going to start drafting up a small paper on this topic, starting with a thorough literature review. I have already read most of the research, so it is simply a matter of organizing the information in a coherent manner.

Finally, I spent some time last week writing my first programming language interpreter. I got my inspiration from the _Crafting Interpreters_ book and worked through the first interpreter implementation - a tree-walk interpreter written in Java. Next up is a bytecode virtual machine written in C. Working through these language implementations is giving me a much deeper understanding of the nuances of designing DSLs, which I think is ultimately where my research interests lie.
