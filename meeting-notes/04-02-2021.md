### JIT Compilation for User-Defined Functions

Meeting Notes

_April 2nd, 2021_

### Notes

The big takeaway from today's meeting was setting a short-term "sprint" objective of completing the integration of all of the "upper layers" of the code required for UDF JIT compilation by the end of next week. Based on my current rate of progress this is a pretty ambitious goal, but at the same time it is definitely the case that I have not been devoting the degree of attention to this project that it deserves thus far. 

Andy and I define the "upper layers" that we want integrated by the end of next week as essentially everything above the execution engine, but including the code generation layer. More specifically, we should have the following layers integrated by the end of next week:

- Network
- Parser
- Binder
- Catalog
- Traffic Cop
- Execution Engine: Abstract Syntax Tree
- Execution Engine: Semantic Analysis
- Execution Engine: Compiler

The majority of these components represent relatively simple integration tasks. For instance, the Network and Parser layers are almost entirely self-contained, meaning that they can be integrated in isolation. Others constitute more complex integration tasks. For instance, the Abstract Syntax Tree layer of the Execution Engine imposes changes on may other parts of the system, both above and below. For this reason, it will likely be difficult to integrate this component in isolation and still expect the system to compile and link. For these layers I will either have to stub out various sections of code to complete the build in the absence of complete functionality, or just accept commits that fail to build.

Overall, I am still optimistic regarding my ability to accomplish this goal by the end of the coming week.
